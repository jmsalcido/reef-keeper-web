# Experimento QR

QR generado localmente desde APP_STORE_URL. No usa redirector ni servicio externo, no contiene identificadores ni datos de usuarios. La alternativa textual abre exactamente la misma ficha. El test decodifica el PNG y compara el resultado con la constante del enlace.

Hipótesis: facilitar continuidad desktop→iPhone. No es un enlace profundo al primer acuario y no atribuye una instalación a una persona. No se añaden señales ni tracking; análisis separado si se aprueba un contrato de medición.

Regenerar con `npm run generate:qr` si cambia APP_STORE_URL; el test detecta divergencias.
